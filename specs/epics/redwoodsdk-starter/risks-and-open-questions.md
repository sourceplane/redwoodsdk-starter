# Risks and open questions — redwoodsdk-starter

| # | Risk | Mitigation / decision |
|---|---|---|
| RW-A | The deploy on a real account is proven only by a live bootstrap: the `d1-edit` mint, the D1 apply and its wiring publish, the migrations against the real D1 API, `wrangler deploy` of the Vite build through `wrangler.deploy.jsonc`, the smoke on workers.dev. | Baseline CI runs the stage lanes' own steps in the tree orun stages: the build with the stage document's database id, the dry deploy, the migrations against a stand-in D1 API over real SQLite, and the built Worker served under `wrangler dev` — the notice and 503 before the schema, the smoke after it, a note added and removed through the page's own server functions, a cross-origin call refused. OPEN until a bootstrap. |
| RW-B | No passkey addon: RedwoodSDK's passkey sign-in keeps its sessions and WebAuthn credentials in Durable Objects, which Orun has no composition for. | Left out, said so in the README and the welcome stays as upstream ships it (the starter has no sign-in either). An owner adding the addon needs a Durable Object binding the pipeline does not provision. ACCEPTED. |
| RW-C | `wrangler.deploy.jsonc` restates what the Cloudflare Vite plugin generates (`dist/worker/wrangler.json`): the built entry, `no_bundle`, the ES-module rules, `../client` as assets. A plugin release that changes its output shape would deploy a stale config. | The plugin is pinned exactly (1.50.0); tests/web holds the two templates to each other, and the e2e dry-deploys and serves the build through the deploy config. An upgrade is a deliberate change. ACCEPTED. |
| RW-D | D1 caps a database's size and has no interactive transactions. | The notes table needs neither. ACCEPTED. |
| RW-E | The migrations package is named `@saas/db` in a tree whose other packages are `@app/*`. | stack-tectonic's db-migrate composition builds `--filter=@saas/db`. ACCEPTED. |
| RW-F | TypeScript 7.0.2 (upstream's pin) type-checks the app, but typescript-eslint's parser takes TypeScript below 6.1. | `tooling/eslint` carries its own TypeScript 5 devDependency, so the linter resolves that one; the app's `tsc` is 7. ACCEPTED. |
| RW-G | A server function is callable by anyone who can reach the Worker: the notes are a public demo table. | RedwoodSDK refuses a cross-origin action (Origin must be the site's own); notes are trimmed and capped at 280 characters; there is no sign-in to scope them by. The README calls the table a demo of the binding. ACCEPTED. |
